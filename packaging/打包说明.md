# TitanPlanner MSI 打包说明

> 仓库目录：`packaging/` —— 打包工具与产物统一存放处。
> 打包方式：WiX Toolset（wix.exe 扫描构建产物生成安装清单 → candle 编译 → light 链接成 MSI）。

---

## 一、目录内容

| 文件 | 作用 |
|---|---|
| `打包.bat` | **双击入口**（推荐）：一键调用打包脚本，运行完自动暂停显示结果 |
| `build - MSI.ps1` | 打包主脚本（全自动版）：检查产物、清理重复插件、编译 wix.exe、自动获取 WiX、生成 MSI |
| `TitanPlanner-Installer.msi` | 打包产物（每次打包后生成于此，不入库） |

> 注意：`Msi/` 目录是 WiX 工程目录（构建链的一部分，已被 .gitignore 忽略），脚本会在打包时自动编译其中的 `wix.exe`，无需手动准备。

---

## 二、在新电脑上打包（三步）

### 第 1 步：准备代码与环境

1. 拉取代码（仓库根为 `F:\TitanPlanner` 或任意目录均可，脚本自动定位上级目录为仓库根）：

   ```bash
   git clone <你的仓库地址> TitanPlanner
   ```

2. 安装 **Visual Studio**（2019/2022/2026 均可，需含 **MSBuild** 组件；脚本通过 vswhere 自动定位 MSBuild）。

3. 无需手动安装 WiX Toolset —— 脚本找不到时会**自动下载**（GitHub 直链 + 国内加速源轮询）到 `%LOCALAPPDATA%\wix314`，一次下载后续复用。

### 第 2 步：构建 Release

用 Visual Studio 打开 `MissionPlanner.sln` → 解决方案配置选 **Release** → 生成解决方案。

> 必须等到 `bin\Release\net461\MissionPlanner.exe` 生成，否则脚本会提示先构建。

### 第 3 步：双击打包

进入 `packaging/` 文件夹，**双击 `打包.bat`**：

- 脚本自动执行：检查产物 → 清理重复插件 → 编译 wix.exe（首次）→ 定位/下载 WiX → 生成 installer.wxs → candle → light
- 完成后提示：`打包完成！MSI 已生成：...\packaging\TitanPlanner-Installer.msi`
- 也可以手动执行：`powershell -NoProfile -ExecutionPolicy Bypass -File "packaging\build - MSI.ps1"`

## 三、脚本功能逐段说明（build - MSI.ps1）

| 步骤 | 功能 | 说明 |
|---|---|---|
| 1/5 | 检查 Release 产物 | 校验 `bin\Release\net461\MissionPlanner.exe` 是否存在，缺失则中止并提示先构建 |
| 2/5 | 清理 plugins 重复副本 | 删除 `plugins/` 中与主目录同名的文件（官方 installer.bat 同款逻辑），避免 MSI 重复打包 |
| 3/5 | 编译 wix.exe | `Msi\net472\wix.exe` **不存在**或 `wix\Program.cs` **源码更新**时，用 vswhere 定位 MSBuild，编译 `wix/wix.csproj`（Release/AnyCPU），输出到 `Msi\`；两者都无变化则跳过编译直接复用 |
| 4/5 | 定位/自动下载 WiX | 依次检查 `$env:WIX` → `%LOCALAPPDATA%\wix314` → 标准安装路径；都没有则自动下载 wix314-binaries.zip（约 41 MB）并解压；下载源轮询：GitHub 直链 → ghfast.top → gh-proxy.com |
| 5/5 | 打包 MSI | 运行 wix.exe 扫描 `bin\Release\net461` 生成 `installer.wxs` → candle 编译 → light 链接（含 difxapp 驱动扩展）→ 输出 `packaging\TitanPlanner-Installer.msi`。**安装清单自动包含：开始菜单快捷方式「LAI GCS」+ 桌面快捷方式「LAI GCS」（安装后自动创建，卸载时自动移除）** |

## 四、常见问题

**Q1：双击 `打包.bat` 闪退/没反应？**
- 确保 `打包.bat` 与 `build - MSI.ps1` 在同一目录（`packaging/`）。
- 若系统阻止运行脚本，右键 `打包.bat` → 以管理员身份运行。

**Q2：提示"未找到 Release 构建产物"？**
- 尚未构建 Release，或构建输出目录不是 `bin\Release\net461`（确认 VS 配置为 Release、平台 Any CPU）。

**Q3：WiX 自动下载失败？**
- 脚本已轮询 3 个下载源，若均失败（网络受限），请手动下载：
  `https://github.com/wixtoolset/wix3/releases/download/wix3141rtm/wix314-binaries.zip`
  解压到 `%LOCALAPPDATA%\wix314`（需含 candle.exe / light.exe / difxapp_x86.wixlib），再重新双击 `打包.bat`。
- 也可设置环境变量 `WIX` 指向已解压目录，脚本优先使用。

**Q4：wix.csproj 编译失败？**
- 确认 Visual Studio 已安装 MSBuild 组件（vswhere 找不到时会明确提示）。
- 编译输出目录：`Msi\`（若被清理，脚本会自动重建）。

**Q5：MSI 体积很大（约 127 MB）？**
- 正常。打包包含完整运行环境（含各子模块 DLL、插件、驱动安装包等）。

**Q6：安装后桌面/开始菜单没有图标？**
- 安装清单默认生成桌面快捷方式「LAI GCS」与开始菜单快捷方式（含卸载项）。若没有，请确认：重新打包时 `wix\Program.cs` 有更新会**自动重编译 wix.exe**（脚本第 3 步会检测源码时间戳）；请使用**最新打包**的 MSI 安装（旧 MSI 不含此功能）。
- 桌面快捷方式为**公共桌面**（所有用户），卸载 MSI 时自动删除。

## 五、打包原理（速览）

```
bin\Release\net461（VS 构建产物）
      │   wix.exe 扫描目录（自动生成文件清单、升级码、驱动信息）
      ▼
installer.wxs（安装脚本清单）
      │   candle.exe 编译（WiX 编译器）
      ▼
installer.wixobj
      │   light.exe 链接（WiX 链接器）+ difxapp 驱动扩展
      ▼
TitanPlanner-Installer.msi（最终安装包）
```
